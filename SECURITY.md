# Security

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/Wheemer/ha-average/security/advisories/new).
Include the affected version, a description of the impact and reproducible steps.
Keep credentials, tokens and private Home Assistant configuration out of public
issues and pull requests.

Security fixes are developed on `dev` and included in subsequent fork releases.
Original-author attribution and licence information remain in the README and LICENSE.md.
