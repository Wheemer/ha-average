## 🎉 Average Sensor v2.5.1

This release fixes YAML import conflicts, temperature calculations and history refreshes, and adds configurable safeguards for large or slow Recorder queries.

### ✨ What changed

- Add `max_history_period` in YAML and UI, defaulting to 31 days. Oversized history windows are rejected rather than silently shortened.
- Add `history_query_timeout` in YAML and UI, defaulting to 60 seconds. Timed-out queries remain tracked until SQL finishes, preventing overlapping replacement queries.
- Raise the minimum supported Home Assistant version to **2026.4.0**.
- Remove the unnecessary runtime dependency on pip.

### 🛠️ Fixes

- Prevent conflicting YAML unique IDs from overwriting an existing sensor. Separate legacy definitions retain their existing identities.
- Add an actionable Repairs notice for ambiguous edits to imported YAML sensors without explicit IDs, allowing the existing entry and sensor ID to be preserved.
- Restore defaults when optional settings are removed from active YAML and reloaded. Show clearer errors for invalid imports and reject blank UI names.
- Fix temperature averages changing with source order and stale temperature metadata after source changes, including recorded history and selected temperature attributes.
- Reject boolean, infinite and NaN fallback values, discard invalid restored readings and prevent nonfinite results or weighted-calculation overflow.
- Correct sub-second history calculations and clamp weighting timestamps to the requested interval.
- Recover cleanly when Recorder is unavailable, with retries and fewer repeated warnings.
- Clean up pending refreshes during reload and shutdown while preserving running SQL tracking. Clear stale values and partial diagnostics after failed or cancelled calculations.
- Include undefined-value substitutions in diagnostic counts and extrema, and apply the configured precision to trend projections.
- Suppress repeated conversion, missing-history and malformed-boundary warnings while allowing recovery. Avoid logging complete source State objects.
- Normalize legacy duration formats and handle template errors with non-string arguments safely.
- Fix compatibility with Home Assistant's internal state handling and configuration-form APIs.
